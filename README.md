# 📊 E-Commerce Sales Dashboard

An interactive **E-Commerce Sales Dashboard** developed using **Power BI** to analyze sales performance and provide business insights through visual reporting.

## 📌 Project Overview

The objective of this project is to analyze e-commerce sales data and help stakeholders understand key business metrics such as:

- Revenue
- Quantity sold
- Profit
- Category and sub-category performance
- Customer behavior
- Payment preferences
- State and city-wise sales
- Monthly sales and profit trends

## 🎯 Key Business Questions

This dashboard addresses the following questions:

1. Which states contribute the most revenue?
2. Which product categories and sub-categories are top-performing?
3. What are the month-over-month sales trends?
4. Who are the top customers by sales?
5. What are the most used payment modes?
6. In which months do we gain or lose profit?

## 📈 Dashboard KPIs

The dashboard presents key metrics as KPI cards:

- **Total Revenue**
- **Total Quantity Sold**
- **Overall Profit**
- **Per Unit AOV**
